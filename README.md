# kromar-site

Public legal pages for **Kromar** (`app.kromar.film`), the iOS and Google Play edition of the app.

- `privacy-policy.html` — privacy policy in English, 日本語, 한국어, 繁體中文, 简体中文
- Hosted with GitHub Pages: <https://qing1989.github.io/kromar-site/privacy-policy.html>

Source of truth lives in the app repository at `docs/privacy-policy.html`; this repo publishes the copy.
